# Alert rules

Le regole applicative sono highlight conservativi, non sostituiscono gli avvisi ufficiali.

- Vento: warning con vento sostenuto ≥45 km/h oppure raffiche ≥60 km/h.
- Pioggia: info con precipitazione corrente ≥5 mm.
- INGV: i comunicati sono mostrati con il testo del provider, senza tradurli autonomamente in “safe/unsafe”.
- Copertura: `FULL` solo quando tutte le fonti contestualmente attive hanno dati live/cache; `PARTIAL` quando una fonte pertinente è non configurata, indisponibile o in errore.

News, Protezione Civile, chiusure stradali, incendi, aeroporti, traghetti e scioperi restano esplicitamente non configurati finché non viene integrata una fonte verificata.
